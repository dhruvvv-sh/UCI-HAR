      Abstract—Smartphones carry accelerometers and gyroscopes that can sense human motion continuously, but raw readings do
      not name the activity being performed. A practical AIoT system must classify activity accurately and fast enough to run on
      a phone or edge node. This report compares six supervised classifiers (Logistic Regression, Decision Tree, Random Forest,
      RBF-kernel SVM, XGBoost and k-Nearest Neighbours) on the UCI Human Activity Recognition Using Smartphones dataset
      (30 subjects, six activities, 561 features) using accuracy, macro F1-score and inference time. Logistic Regression gives the best
      overall trade-off: 96.06% accuracy, 96.06% macro F1 and 4.135 ms to classify all 2,947 test windows. The Decision Tree is
      marginally faster but loses about 9.8 accuracy points, while the SVM is the second most accurate but roughly 290 times slower
      than Logistic Regression. We propose an edge-first AIoT pipeline built around the lightweight classifier. The deployment itself
      is proposed work and has not been validated on hardware.
      Keywords—AIoT, human activity recognition, smartphone sensors, edge inference, latency, Logistic Regression, machine learn-
      ing.

   The limitations listed above, chiefly single-run timing,
batch rather than end-to-end latency, no tuning and no real
device test, restrict how far the results can be generalised.
Future work includes deploying Logistic Regression on
a smartphone or Raspberry Pi-class device and measuring
end-to-end latency including feature extraction; recording
memory, CPU and energy use; repeating timing runs and re-
porting mean, standard deviation and percentiles; applying
feature selection or dimensionality reduction to the 561 in-
puts; testing quantised or compressed models; using cross-
validation and hyperparameter optimisation; evaluating on
real-time streams in uncontrolled settings; adding transition,
fall-detection and abnormal-activity classes; and exploring
privacy-preserving approaches such as federated learning.
