      Abstract—Smartphones carry accelerometers and gyroscopes that can sense human motion continuously, but raw readings do
      not name the activity being performed. A practical AIoT system must classify activity accurately and with low inference cost
      on a phone or edge node. This report compares six supervised classifiers (Logistic Regression, Decision Tree, Random Forest,
      RBF-kernel SVM, XGBoost and k-Nearest Neighbours) on the UCI Human Activity Recognition Using Smartphones dataset
      (30 subjects, six activities, 561 features) using accuracy, macro F1-score and repeated batch inference time. Logistic Regression
      achieved the strongest overall result, with 96.064% accuracy, 96.056% macro F1-score and a median batch inference time of
      0.531 ms for 2,947 test windows. In the repeated benchmark, it achieved the best result on all three primary evaluation criteria.
      We propose an edge-first AIoT pipeline built around this lightweight classifier. The edge deployment is proposed work and has
      not been validated on actual hardware.
      Keywords—AIoT, human activity recognition, smartphone sensors, edge inference, latency, Logistic Regression, machine learn-
      ing.

   Future work includes deploying Logistic Regression on
a smartphone or Raspberry Pi-class device and measuring
single-window and end-to-end latency including feature ex-
traction; recording memory, CPU and energy use; applying
feature selection or dimensionality reduction to the 561 in-
puts; testing quantised or compressed models; using cross-
validation and hyperparameter optimisation; evaluating on
real-time streams in uncontrolled settings; adding transition,
fall-detection and abnormal-activity classes; including re-
cent and independent edge, TinyML and lightweight HAR
studies in the survey; and exploring privacy-preserving ap-
proaches such as federated learning.
